# MikeyVerse Audio Studio — Website v1.0

Frontend React/Vite prepared for deployment to Vercel.

## Deploy settings
- Framework: Vite
- Build command: `npm run build`
- Output directory: `dist`
- Root directory: project root

The frontend calls the existing Render backend at `https://mikeyverse-audio-studio.onrender.com`.
Do not add the Gemini API key to this frontend. Keep it only in Render environment variables.
